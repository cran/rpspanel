Getting started with rpspanel

rpspanel builds a documented, reproducible state-by-year panel for the 50 US states and DC. It combines EIA energy, electricity and CO2 data, BEA GDP, income and population, and standardised Renewable Portfolio Standard (RPS) stringency measures.

library(rpspanel)

API keys

EIA and BEA data need free API keys:

  • EIA: https://www.eia.gov/opendata/register.php
  • BEA: https://apps.bea.gov/API/signup/

Put them in your .Renviron file (open it with usethis::edit_r_environ()), then restart R:

EIA_API_KEY=your-eia-key
BEA_API_KEY=your-bea-key

One call, one panel

panel <- build_panel(years = 2005:2022)
panel

Pick variables by group or by name. Derived variables fetch what they need:

small <- build_panel(
  states = c("CA", "TX", "NY", "IA"),
  years  = 2010:2022,
  vars   = c("co2_pc", "re_share_nonhydro", "gdp_real_pc", "rps_nominal")
)
head(small)

If one source cannot be reached, its variables are left out with a warning and the rest of the panel is still returned.

Caching and vintages

Downloads are cached, so a panel can be rebuilt offline with exactly the same data vintage. Use refresh = TRUE to download fresh data, rps_cache_list() to see what is cached and rps_cache_clear() to empty the cache.

rps_cache_dir()
#> [1] "C:\\Users\\Mosdam\\AppData\\Local\\Temp\\RtmpycXlx5/rpspanel-vignette"

RPS measures without API keys

RPS stringency measures come from the coded rules bundled with the package, so they work offline:

rps <- build_panel(states = c("CA", "WA", "NC", "TX"), years = 2005:2025,
                   groups = "rps",
                   rps_methods = c("adoption", "nominal", "flexibility"))
rps[rps$year %in% c(2010, 2020), ]

Estimation and export

The panel works directly with plm, fixest and csdm:

library(fixest)
p <- build_panel(years = 2001:2022, vars = c("co2_pc", "rps_nominal", "gdp_real_pc"))
feols(log(co2_pc) ~ rps_nominal + log(gdp_real_pc) | state + year,
      data = as_pdata(p, "fixest"), cluster = ~state)

Export to CSV, Stata or Parquet, with the codebook alongside:

f <- file.path(tempdir(), "rps_panel.dta")
if (requireNamespace("haven", quietly = TRUE)) export_panel(rps, f)
